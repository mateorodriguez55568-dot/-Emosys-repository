¿Qué es EMOSYS?

EMOSYS es un sistema inteligente basado en Arduino Nano que utiliza sensores biométricos para estimar el estado emocional del usuario mediante la medición de la frecuencia cardíaca y la temperatura corporal.

La información obtenida se procesa y se presenta en una interfaz web sencilla para facilitar la interpretación de los resultados.

¿Cómo funciona?

El sistema registra datos biométricos mediante:

  • ❤️ Sensor KY-039 → Frecuencia cardíaca
  • 🌡️ Sensor MLX90614 → Temperatura corporal

Para obtener una lectura estable se recomienda mantener el dedo sobre los sensores durante aproximadamente 15 segundos.
